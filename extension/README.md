# BSL-модули

Обезличенные алгоритмы, не готовое расширение.

| Адаптер | Ответственность |
|---|---|
| **Транспорт** | HTTP-вызов и одна повторная авторизация |
| **Очередь** | Захват, состояния и повторы |
| **Карта ID** | Связи ID и конфликты миграции |
| **Журнал** | Код, время и очищенный ответ |

Для реализации нужны собственные метаданные очередей, карты ID, журнала и прав доступа.

## Переиспользуемые компоненты

- `HrIntegrationQueuePolicy` — чистая политика claim/lease, повторов и состояния `ОтложеноНавсегда`;
- `HrIntegrationQueueRepository` — атомарный репозиторий с оптимистической проверкой версии;
- `HrIntegrationDTOMapper` — декларативный маппинг плоских DTO с внедряемым преобразователем;
- `HrIntegrationAttachments` — проверка, SHA-256 и идемпотентное сохранение вложений.

Репозиторий очереди передается как адаптер. Он должен атомарно реализовать `ДобавитьЕслиОтсутствует()` и
`ОбновитьЕслиВерсия()`. Время передается параметром, поэтому истечение аренды и повторы можно проверять
детерминированно без ожидания реального таймера.
