# Безопасность

| Риск | Контроль |
|---|---|
| Секрет в исходниках | Внешнее защищённое хранилище |
| ПДн в журнале | Очистка полей до сериализации |
| Утечка документа | Вложения и формы не журналируются |
| Повторная отправка | Ключ идемпотентности и уникальность очереди |
| Подмена внешнего ID | Проверка конфликта перед миграцией |
| Случайный внешний вызов | Mock слушает только `127.0.0.1` |

## Журнал

Записываются:

- операция и направление;
- HTTP-код и длительность;
- номер попытки и состояние;
- ограниченное очищенное тело ответа.

Не записываются:

- заголовки авторизации и секреты;
- налоговые и персональные данные;
- свободный текст неизвестной ошибки;
- бинарные вложения и печатные формы.

Неизвестные поля удаляются. Разрешённые строки ограничиваются по длине и формату.
